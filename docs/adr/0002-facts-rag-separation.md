# ADR-0002：结构化事实与 RAG 证据分离

状态：Accepted

目录价格、型号、规格和可售状态以MySQL `product`为事实来源；功能解释、适配条件、地区限定等取带商品及活动版本过滤的RAG资料。目录比较完全使用字段白名单，缺失显示“暂无数据”；未知报价为NULL，不能由文档或模型猜测。

原因：检索相关性不足以授权事实变更。当前商品回答由模型选择编号，`GroundedAnswerComposer`校验后拼接当前目录事实或完整文档段落，历史消息只用于理解指代。它保留原有条件，代价是首字等待和摘录式表达；选错/漏选、源材料错误及目录与文档冲突仍需逐项检查，分离并未实现自动事实冲突裁决，也不是通用零幻觉保证。
